# S3

Global storage service of data(files) in form of Objects in buckets(directories/folder i.e. globally **UNIQUE NAME** across all regions all accounts defined at region level)!

^^OBJECT^^

- No concept of directories on S3. 
- Each object => 2 parts (PREFIX + OBJECT NAME). 
- Full path of object called as **KEY**. 
- Max size 1 object = 5TB (>5GB file use multi-part upload)


### What is it used for?
- store data (Data lakes & big data analytics) as infinitely scaling 
- integration into AWS services
- website backbone (Static website)
- Application hosting
- Media hosting
- Software delivery
